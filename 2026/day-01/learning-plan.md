# 90-Day DevOps Learning Plan

## Current Level

I am a B.Tech CSE student specializing in Cloud Computing and Virtualization Technology. I have a foundation in AWS, Git/GitHub, Docker, GitHub Actions/Jenkins, SQL and Java. I have also worked on cloud-based projects and gained practical exposure to DevSecOps through an internship. My current gap is that I know several individual tools, but I want to develop stronger Linux, automation, CI/CD, infrastructure and production-deployment skills.

## Why I Am Learning DevOps & Cloud

I want to build practical skills for a career in Cloud/DevOps/SDE roles. My goal is to move beyond learning individual tools and understand how they work together to build, deploy, monitor and maintain reliable applications. I want to become capable of troubleshooting real deployment and infrastructure problems independently.

## My 3 Goals for the Next 90 Days

1. **Build strong DevOps fundamentals** by becoming comfortable with Linux, networking, Bash scripting, Git and troubleshooting.

2. **Build CI/CD and Infrastructure skills** by creating automated pipelines using GitHub Actions/Jenkins, containerizing applications with Docker and learning Infrastructure as Code using Terraform with AWS.

3. **Deploy and operate a real application** on AWS with CI/CD, monitoring, logging and basic security practices, and document the complete project on GitHub.

## 3 Core Skills I Will Build

* Linux administration, networking and troubleshooting
* CI/CD, automation and DevSecOps practices
* Docker, Terraform, AWS and Kubernetes fundamentals

## Weekly Time Commitment

* **Weekdays:** 1–1.5 hours/day
* **Weekends:** 2–2.5 hours/day
* **Target:** approximately 9–12.5 hours/week

My priority will be hands-on practice and projects rather than only watching courses.

## Consistency System

I will maintain a daily learning log and commit my practical work to GitHub whenever appropriate. Every week I will review what I learned, identify gaps and plan the next week's tasks. On difficult days, I will focus on completing at least one small task rather than skipping the day completely.

## 90-Day Outcome

By the end of 90 days, I want to be able to explain and practically demonstrate how a modern application moves from code to a deployed, monitored and maintainable environment using Linux, Git, CI/CD, Docker, Terraform and AWS, with an understanding of Kubernetes and DevSecOps practices.
